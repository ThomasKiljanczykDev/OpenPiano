# Documentation guidelines

- **Docs as code.** Update the relevant doc in the same commit/PR as the code change it describes,
  not as a follow-up.
- **Links.** Use relative Markdown links between docs in this repo (e.g. `../AGENTS.md`),
  so they resolve the same on GitHub and locally.
- **Diagrams.**
  Prefer a Mermaid code block over a static image for architecture or flow diagrams — it stays diffable and doesn't rot as a stale screenshot.
- **Language.** English only.
- **Filenames.** kebab-case, e.g. `kotlin-android.md`.
